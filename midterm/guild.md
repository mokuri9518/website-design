# Web Programming Midterm Project: My Digital Guide: Interactive Website

## 1. Project Overview

Create a functional, visually appealing, and interactive website on a topic of your choice. Your website should provide useful information or services to visitors.

**Example Topics:**

* Travel Guide
* Restaurant or Food Guide
* College Survival Guide
* Personal Fitness Guide
* Pet Care Guide
* Music or Movie Recommendation Website
* Cafe or Small Business Website
* Event Guide

Be creative and develop your own ideas.

---

## 2. Technical Requirements

Your website **must be developed using ONLY HTML, CSS, and JavaScript**.
It must meet the following requirements:

### A. HTML - Structure & Content

Your website must include:

1. Appropriate headings and paragraphs.
2. At least four (4) interconnected HTML pages.
3. A navigation menu on every page allowing users to navigate directly to all pages.
4. At least one $2 \times 2$ grid layout (using HTML `<div>` elements and CSS. Each cell must contain meaningful content).
5. Images with proper alternative text (`alt` attribute).
6. Ordered or unordered lists.
7. At least one meaningful HTML table.
8. Internal and external hyperlinks.
9. Good HTML document structure.

Your content should be well-structured, meaningful, and relevant to your chosen topic.

### B. CSS - Design & Layout

Your website must include:

1. External CSS file(s).
2. Consistent visual design across all pages (e.g., consistent color palette, fonts, navigation menu, header, and footer).
3. Appropriate colors, typography, spacing, and backgrounds.
4. CSS used to layout the website.
5. Hover effects for interactive elements.
6. Good readability and usability.

You are encouraged to explore additional CSS properties to enhance your design.

### C. JavaScript - Interactivity

Your website must include at least two (2) meaningful interactive features implemented using JavaScript.

**Examples include:**

* Interactive buttons that change page content.
* A simple calculator.
* A shopping cart with total price calculation.
* An interactive quiz.
* A dynamic table generated using JavaScript.

These two interactive features must serve different purposes and demonstrate JavaScript and DOM manipulation.

## 3. Code Explanation Report

In addition to your website, you must submit a **Code Explanation Report (DOCX)**.

Your report must include:

### A. Project Introduction

* What is the purpose of your website?
* Who is the target audience?
* Why did you choose this topic?

### B. Website Structure

* Describe the purpose of each HTML page.
* Explain how users navigate between pages.

### C. HTML and CSS Explanation

* Choose at least three (3) HTML elements used in your website and explain their purpose.
* Choose at least three (3) CSS properties and explain how they affect the appearance or layout of your website.

### D. JavaScript Explanation

For each interactive feature:

1. Explain what the feature does.
2. Include the relevant JavaScript code.
3. Explain how the code works.
4. Explain how JavaScript interacts with HTML elements.

### E. Reflection

* What was the most challenging part of this project?
* What did you learn?
* What would you improve if you had more time?

## 6. Programming Restrictions

***Only HTML, CSS, and JavaScript are allowed.***

The following are **NOT** allowed:

* Website builders (Wix, WordPress, etc.)
* Front-end frameworks (React, Vue, Angular, etc.)
* CSS frameworks (Bootstrap, Tailwind CSS, etc.)
* JavaScript libraries (jQuery, etc.)
* Pre-built website templates

All website structure, styling, and interactive functionality must be implemented using HTML, CSS, and vanilla JavaScript.
