02 — MAKE IT WORK

用網頁技術，
把體驗做好。

HTML 安排內容、CSS 設計視覺、JavaScript 加入互動。先確保每一頁都清楚好讀，再為使用者加上真正有幫助的功能。

HTML 結構CSS 版面JavaScript 互動
01 / THE BUILDING BLOCKS

三種技術，各司其職。

01 / STRUCTURE</>

HTML 說清楚內容

用標題、段落、清單與表格組織資訊。選擇有意義的語意標籤，讓人和輔助工具都容易理解頁面。

JavaScript 回應操作

02 / DESIGN FOR PEOPLE

畫面漂亮之外，也要用得順手。

↗

先照顧閱讀體驗。

對比清楚、文字容易讀、導覽位置一致。這些基本功比堆疊裝飾更能讓使用者留下來。

認識網頁無障礙 ↗
  • 01
    用標題建立層次

    每頁只有一個主要標題，副標題依序分層，讓人快速找到重點。

  • 02
    替圖片補上替代文字

    描述圖片的重要資訊；純裝飾圖片則使用空的 alt 屬性。

  • 03
    讓所有頁面容易往返

    每頁都放上完整導覽，並標出目前所在頁面。

  • 04
    小螢幕也能舒服閱讀

    使用彈性版面，並在手機上檢查文字、按鈕和表格。

03 / KEEP IT ORGANIZED

簡單的檔案結構，更容易維護。

把頁面、共用樣式和互動程式分開放，日後要修改時，會更快找到正確的位置。
